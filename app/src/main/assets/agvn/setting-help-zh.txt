# AGVN Player：每个设置项旁边“?”按钮的说明（简体中文）。
# 每项 4 行：[设置项的越南语名称，是查找用的键，不要翻译]，然后是三行说明，行首前缀保持越南语不变。
# 以“#”开头的行是注释。缺少三行之一的项不会显示“?”按钮。

[Async]
Là gì: 在后台编译着色器（绘制特效的代码），不让游戏停下来等。只对名字带 async 或 gplasync 的 DXVK 版本有效。
Vì sao chỉnh: 减少第一次遇到新场景或新特效时的卡顿。
Chỉnh thế nào: 选 async 版 DXVK 时通常会自动开启；建议保持开启，低配手机更是如此。如果物体或特效一闪就没了、闪烁，或游戏出错，就试试关闭。

[Biến]
Là gì: 选择要添加的环境变量。环境变量是打开游戏时发给 Wine、驱动或 DXVK 的一行设置。选“自定义…”可以自己输入名称。
Vì sao chỉnh: 有人指导你添加某个变量来修复问题或测试性能时使用。
Chỉnh thế nào: 只添加你清楚用途的变量。选好名称后点“添加”，再调整“值”。游戏里设置的变量会覆盖运行环境中同名的变量。

[Box64 Preset]
Là gì: Box64 和 WOWBox64 的预设，在稳定和速度之间取舍：稳定、兼容、折中、性能（从最安全到最快）。
Vì sao chỉnh: 游戏闪退、卡死或出现奇怪错误时调整（选更安全的档），或游戏运行正常但慢时调整（选更快的档）。
Chỉnh thế nào: 默认：“兼容”。游戏出错：试试“稳定”。想更快：先试“折中”再试“性能”，出错就改回来。Unity 游戏建议用“兼容”或“稳定”。

[Bật debug Wine]
Là gì: Wine 是让 Windows 游戏在手机上运行的部分。开启后，Wine 会把警告和错误写进 AGVN-Player/logs 文件夹中的日志文件，游戏菜单里也会多一个“查看日志”按钮。
Vì sao chỉnh: 游戏闪退、卡死或报错，需要把日志发给 AGVN 求助时使用。
Chỉnh thế nào: 默认关闭。开启后打开游戏直到出错，退出游戏，然后在游戏库中点该游戏的 ⋮ →“发送日志”（含 Wine 日志），或点“设置”顶部的“导出错误日志”。“Wine 调试通道”保持默认即可。用完记得关闭，因为记录日志会让游戏变慢。

[Bật DInput]
Là gì: DInput（DirectInput）是一种较老的手柄读取方式，常见于老式 PC 游戏。
Vì sao chỉnh: 老游戏识别不到手柄时开启。“独占输入”开启时，开启 DInput 会自动关闭 XInput：游戏只能通过 DInput 看到手柄，把它当成普通手柄而不是 Xbox 手柄。
Chỉnh thế nào: 默认关闭。只有“独占输入”开启时才能调整。如果按键错乱，就改回“开启 XInput”，或关闭“独占输入”，让游戏通过两种方式都能看到手柄。

[Bật File Provider]
Là gì: 允许用 Android 的文件管理器（“文件”应用）查看和复制 AGVN Player 里的文件（比如虚拟 Windows 电脑的 C 盘）。
Vì sao chỉnh: 需要把存档、字体或配置文件复制到游戏的 C 盘时很方便。如果用不到，也不想让其他应用看到本应用的数据，可以关闭。
Chỉnh thế nào: 默认开启。更改在下次打开应用时生效。在里面删除或重命名文件要小心，可能会弄坏运行环境。

[Bật log Box64]
Là gì: Box64 是一个转译器，让为电脑芯片（x86）写的程序能在手机芯片（ARM）上运行。开启后，Box64 会往游戏日志里写入更多信息。
Vì sao chỉnh: 游戏一打开就闪退或卡死，AGVN 需要看看 Box64 报了什么时使用。
Chỉnh thế nào: 默认关闭。只有游戏用 Box64 运行，或在“32 位模拟器”中选了 WOWBox64 时才有用；用 FEXCore 时几乎不会多记录什么。报告完问题就关闭。

[Bật nhật ký ứng dụng]
Là gì: 在玩游戏时，把应用本身（Android 部分：图形驱动、声音、屏幕…）的日志记录到 AGVN-Player/logs 文件夹中的一个文件里。
Vì sao chỉnh: 应用自己退出、黑屏或出现游戏之外的错误时很有用，能帮 AGVN 找出原因。
Chỉnh thế nào: 默认关闭。只在需要报告问题时开启：开启后玩到出错，再点“导出错误日志”。发送完就关闭，因为每玩一次都会多一个日志文件，占用手机存储。

[Bật tần số quét cao]
Là gì: 刷新率是屏幕每秒刷新的次数（60、90、120 Hz…）。开启后，玩游戏时应用会请求屏幕支持的最高刷新率。
Vì sao chỉnh: 只有游戏能跑到 60 FPS（每秒帧数）以上，并且手机屏幕是 90 Hz 或更高时才有用。
Chỉnh thế nào: 默认关闭。低配手机上游戏通常只有 24–30 FPS，开启也不会更流畅，反而更费电、更发热。低配手机建议保持关闭。

[Bật XInput]
Là gì: XInput 是大多数新 PC 游戏使用的 Xbox 手柄读取方式。
Vì sao chỉnh: 游戏支持 Xbox 手柄时选择。“独占输入”开启时，开启 XInput 会自动关闭 DInput，游戏只能通过 XInput 看到手柄。XInput 和 DInput 都关闭的话，游戏识别不到手柄。
Chỉnh thế nào: 默认开启。只有“独占输入”开启时才能调整。老游戏识别不到手柄时，改用“开启 DInput”。

[Bắt chuột ngoài]
Là gì: 使用外接鼠标（有线或蓝牙）时，应用会把鼠标锁定在游戏里：Android 的指针隐藏，鼠标的移动和按键都直接发给游戏。
Vì sao chỉnh: 让 3D 游戏转视角更顺滑，指针也不会跑出游戏。如果外接鼠标表现奇怪、难以控制或点击没反应，可以试着关闭。
Chỉnh thế nào: 默认开启。不用外接鼠标时此项没有任何影响，触屏照常使用。此项对所有游戏生效。

[Bỏ qua X11]
Là gì: 仅限 DisplayX。开启后，用 Vulkan 绘制的游戏画面（例如通过 DXVK、VKD3D）会直接送到屏幕，不经过中间的 X11 层。
Vì sao chỉnh: 可能降低用 Vulkan 绘制的游戏的延迟并提高 FPS。如果游戏黑屏、不显示画面或闪退，就需要关闭。
Chỉnh thế nào: 默认关闭。想试试更流畅就开启，然后重新打开游戏；画面出错就关掉。不确定就保持关闭。

[Bộ dựng hình]
Là gì: 应用把 Windows 画面画到手机屏幕上的方式。Vulkan：默认，带放大和锐化滤镜。EGL：较老的 OpenGL ES 方式。DisplayX：把画面直接交给 Android。
Vì sao chỉnh: 遇到黑屏、闪烁、颜色不对，或想试试哪种方式在你手机上更流畅时调整。
Chỉnh thế nào: 保持 Vulkan。画面出错就试 EGL。DisplayX 少了复制步骤，可能更轻快，但不能用“放大镜”。更改此项会自动重置“表面格式”。

[Bộ dựng hình Wine]
Là gì: 选择 WineD3D 绘制 3D 画面的方式：gl 使用 OpenGL（通过应用的 OpenGL 驱动），vulkan 直接使用 Vulkan 驱动。只在 DX Wrapper 为 WineD3D 时有效。
Vì sao chỉnh: 使用 WineD3D 的游戏运行慢、画面出错或打不开时调整。
Chỉnh thế nào: 默认：gl，适合大多数游戏。gl 出错时试试 vulkan；WineD3D 的 vulkan 渲染还缺一些功能，老游戏可能画面出错。出错就改回 gl。

[Bộ dựng hình WineD3D]
Là gì: 选择 WineD3D 的绘制方式：gl 使用 OpenGL，vulkan 直接使用 Vulkan 驱动，gdi 完全关闭 3D，只画 2D。只在 DX Wrapper 为 WineD3D 时有效。
Vì sao chỉnh: 使用 WineD3D 的游戏运行慢、画面出错或打不开时调整。
Chỉnh thế nào: 默认：gl，适合大多数游戏。gl 出错时试试 vulkan；老游戏用 vulkan 可能画面出错。gdi 只用于 2D 游戏，因为 3D 游戏会无法运行。

[Bộ nhớ thiết bị tối đa]
Là gì: 告诉游戏的显存（VRAM，单位 MB）大小。0 表示如实报告手机的数值。手机的显存和内存是共用的，所以这只是游戏看到的数字。
Vì sao chỉnh: 有些游戏会按显存自动选画面质量，或者提示显存不足然后不运行。
Chỉnh thế nào: 建议保持 0（默认）。游戏提示显存不足：试试 2048 或 4096。调低这个数字并不能真正省内存（已在真机上测过），只对按显存自动选低画质的游戏有用。

[Bộ nhớ video]
Là gì: WineD3D 告诉游戏的显存（VRAM）大小，单位 MB。这只是报给游戏的数字，不会真的预留内存。
Vì sao chỉnh: 使用 WineD3D 的游戏提示显存不足、不让选高画质或不肯运行时调整。
Chỉnh thế nào: 默认：2048。游戏提示显存不足：试试 4096。调低这个数字不会省内存，DirectX 8/9 游戏还可能提示内存耗尽。低配手机：保持 2048 即可。

[Bộ nhớ video (MB)]
Là gì: WineD3D 告诉游戏的显存（VRAM）大小，单位 MB。这只是报给游戏的数字，不会真的预留内存。
Vì sao chỉnh: 使用 WineD3D 的游戏提示显存不足、不让选高画质或不肯运行时调整。
Chỉnh thế nào: 默认：2048。游戏提示显存不足：试试 4096。调低这个数字不会省内存，DirectX 8/9 游戏还可能提示内存耗尽。低配手机：保持 2048 即可。

[Bộ đệm Async]
Là gì: 把编译好的着色器（绘制特效的代码）存到手机存储里，下次玩时直接复用。只有 gplasync 版 DXVK 才有。
Vì sao chỉnh: 下次玩时卡顿更少，回到去过的场景更流畅。
Chỉnh thế nào: 选 gplasync 版时会自动开启；建议保持开启。会多占一点存储空间。更换驱动或 DXVK 后游戏画面出错：试试关闭。

[Bộ đệm giả lập BCN]
Là gì: 把解压好的 BCn 纹理（PC 格式的压缩表面图像）存到手机存储里，下次直接复用，不用再解压。
Vì sao chỉnh: 让下次游戏加载更快，进入关卡时卡顿更少。
Chỉnh thế nào: 保持关闭（默认）即可。只有应用用 CPU 解压纹理时才有效（Mali 手机，或驱动不是 Turnip）。游戏加载慢就开启；会多占存储空间。

[Bộ đệm shader Async]
Là gì: 把 DXVK 构建好的着色器存到内部存储，下次玩时复用，不用从头再构建。只对名字带 gplasync 的 DXVK 版本有效。
Vì sao chỉnh: 开启后，从第二次玩开始卡顿会减少。
Chỉnh thế nào: 默认：关闭。使用 2.3.1-arm64ec-gplasync 版本时，建议和“Shader Async”一起开启。会多占一点存储空间。开启后游戏出错就关闭。

[Chia sẻ bộ nhớ tạm Android với Wine]
Là gì: 剪贴板是保存你刚复制的文字的地方。开启后，在手机上复制的文字可以粘贴到游戏里，游戏里复制的文字也能粘贴到其他应用。
Vì sao chỉnh: 需要往游戏里粘贴名字、激活码，或把游戏里的文字复制到翻译应用（如果游戏允许复制文字）时很方便。
Chỉnh thế nào: 默认关闭。只共享文字，不共享图片。不需要时就关闭，免得游戏读到你复制过的内容，比如密码。

[Chuột tương đối]
Là gì: 按“移动了多少”的方式把鼠标移动发给游戏，而不是发送指针位置。适用于外接鼠标和触控板式滑动。
Vì sao chỉnh: 用鼠标转视角的 3D 游戏（射击、3D 角色扮演）视角转不动、转得卡顿或卡在屏幕边缘时开启。
Chỉnh thế nào: 默认关闭。视觉小说和点菜单类游戏建议保持关闭。可以直接在游戏菜单里开关（“相对鼠标”开关）来快速试试。

[Chế độ dựng hình]
Là gì: 仅在使用 Turnip 驱动时显示（骁龙芯片、Adreno GPU 的手机）。选择 GPU 的绘制方式：Sysmem 直接画到内存；Gmem 把画面分成小块，在 GPU 的高速内存里画。
Vì sao chỉnh: 游戏画面出错（闪烁、条纹、黑块、画面破碎），或想试试哪种方式 FPS 更高时调整。
Chỉnh thế nào: 保持 None（由驱动自动选择）。画面出错就试 Sysmem。Autotuner Profiled：驱动自己测量后选更快的方式，FPS 可能会波动。其他方式都不行时才试 Gmem。

[Chế độ hiệu năng]
Là gì: 仅限 DisplayX。告诉 Android 发送画面的线程需要跟上刷新率，让系统在需要时提高 CPU 频率。
Vì sao chỉnh: 让画面输出更均匀，减少卡顿。代价是手机可能更热、更费电。
Chỉnh thế nào: 默认开启。手机很快发热或掉电快就试试关闭。需要 Android 13 及以上；更老的手机开不开都一样。

[Chế độ khởi động]
Là gì: 选择打开游戏或运行环境时启用哪些 Windows 后台服务（在 Wine 中）。
Vì sao chỉnh: 少开一些服务可能让启动稍微轻快一点，但有些游戏和安装程序需要这些服务才能正常运行。
Chỉnh thế nào: 保持“精简”（默认）：关闭 Plug and Play（即插即用）和 RPC 服务，更轻快。“普通”：像原版 Wine 一样开启全部服务，游戏或安装程序报服务错误时选它。“极简”会再关闭很多服务，包括 .msi 安装。

[Chế độ trình chiếu]
Là gì: “渲染器”为 Vulkan 时，应用把游戏画面送上屏幕的方式。fifo 按屏幕刷新的节奏等待；mailbox 总是显示最新的一帧。
Vì sao chỉnh: 觉得操作有延迟或画面显示不均匀时调整。
Chỉnh thế nào: 建议保持 fifo（默认，稳定）。想让操作更跟手就试试 mailbox；手机不支持 mailbox 时会自动改用 fifo。低配手机保持 fifo 即可。

[Chế độ trình chiếu của driver]
Là gì: 游戏通过 Vulkan（DXVK、VKD3D、Zink）把画面送上屏幕的方式。mailbox：显示最新一帧。fifo：等屏幕节奏。immediate：不等待。relaxed：类似 fifo，但迟到的帧立即显示。
Vì sao chỉnh: 看到画面闪烁、闪黑、横向撕裂或卡顿时调整。
Chỉnh thế nào: 建议保持 mailbox（默认）。画面闪烁，尤其是通过 Zink 运行的 OpenGL 游戏：试试 fifo。immediate 和 relaxed 可能让画面撕裂，只在需要时尝试。

[Chế độ vẽ ngoài màn hình]
Là gì: WineD3D 绘制还没显示到屏幕上的临时画面的方式：fbo（新方式）或 backbuffer（旧方式）。只在 WineD3D 使用 gl 渲染时有效。
Vì sao chỉnh: 只在使用 WineD3D 的游戏黑屏或画面出错，其他办法都修不好时才更改。
Chỉnh thế nào: 默认：fbo，建议保持不变。其他办法都试过后才试 backbuffer；更糟就改回 fbo。重新打开游戏后生效。

[Chọn nhân CPU]
Là gì: 允许游戏使用的 CPU 核心（CPU0、CPU1…）。白色格子是已选中的核心。
Vì sao chỉnh: 让游戏只用大核，在部分手机上可能运行更平稳。选的核心太少会让游戏变慢。
Chỉnh thế nào: 保持全选（默认）。想试试就只保留大核，通常是编号大的（例如 CPU4–CPU7）。一个都不选的话，游戏会使用全部核心。

[Chọn nhân CPU (ứng dụng 32-bit)]
Là gì: 为这个运行环境中的 32 位程序选择 CPU 核心（处理核心）。不适用于从游戏库打开的游戏：游戏使用其“配置”中的“选择 CPU 核心”。
Vì sao chỉnh: 只在有人指导时才需要，例如很老的 32 位游戏用多核时出错，或想把程序固定在某几个核心上。
Chỉnh thế nào: 建议保持原有选择。点 CPU0、CPU1… 来开关；白色格子是已选中的核心。如果全部取消，应用会自动使用后一半核心（例如 8 核手机上的 CPU4–CPU7）。

[CSMT]
Là gì: CSMT 让 WineD3D 在单独的 CPU 线程上处理绘制命令，和游戏并行运行。只在 DX Wrapper 为 WineD3D 时有效。
Vì sao chỉnh: 使用 WineD3D 的游戏闪退、卡死、闪烁或画面出错时，可以试着关闭。开启时游戏通常更快。
Chỉnh thế nào: 默认：开启，建议保持开启。只有游戏出错、关闭后有改善时才关闭；关闭可能降低 FPS。重新打开游戏后生效。

[Cấu hình phím ảo]
Là gì: 为这个游戏选择屏幕上显示的按键布局。“自动（AGVN）”按游戏类型选择：视觉小说、RPG、2D 或电脑键盘。“关闭虚拟按键”则不显示任何按键。
Vì sao chỉnh: 自动选的布局不适合游戏、缺少需要的按键，或你只想直接触屏或用手柄时调整。
Chỉnh thế nào: 建议保持“自动（AGVN）”。选定某个布局后，应用就不再自动更换。想移动、添加或修改按键，在游戏中点“✎ 编辑”；按键布局会单独保存给这个游戏。

[Cập nhật ứng dụng]
Là gì: 直接在应用里查找并安装新版 AGVN Player，不需要电脑。应用只从 AGVN 的 GitHub 页面下载版本信息和安装文件，不会发送手机的任何数据。
Vì sao chỉnh: 新版本会修复问题，让游戏运行得更好。更新后游戏、存档和设置都会保留。
Chỉnh thế nào: 点进去，选“检查更新”。有新版本就点“更新”，等下载完成后，在 Android 的对话框中点“更新”。文件有几百 MB，建议用 Wi-Fi。

[DDraw Wrapper]
Là gì: 给使用 DirectDraw 或 Direct3D 7 及更早版本的很老的游戏用的转换层。只在 DX Wrapper 为 DXVK+VKD3D 时有效。none 和 wined3d 使用 Wine 自带的 DirectDraw。
Vì sao chỉnh: 很老的游戏黑屏、颜色不对、卡顿、很慢或进不去时调整。
Chỉnh thế nào: 默认：none。老 2D 游戏出错：试试 cnc-ddraw。老 3D 游戏（DirectX 7）画面出错：试试 dd7to9 或 D7VK 2.2（如果有）。重新打开游戏后生效。

[Direct3D]
Là gì: 许多 DirectX 9–11 游戏需要的 DirectX 辅助库（d3dx9、d3dx10、d3dx11、d3dcompiler）。这不是 DXVK；DXVK 在“DX Wrapper”中选择。
Vì sao chỉnh: “原生（Windows）”是微软的正版库，通常运行更正确。“内置（Wine）”是 Wine 自己写的，还缺一些功能，可能让游戏画面出错或闪退。
Chỉnh thế nào: 保持“原生（Windows）”（默认）。只有游戏一打开就闪退、其他办法都不行时，才试“内置（Wine）”。改完后重新打开游戏。

[DirectMusic]
Là gì: DirectMusic 音乐库，一些老游戏用它播放背景音乐。
Vì sao chỉnh: “内置（Wine）”还不完整，所以有些老游戏会没有背景音乐，或播放音乐时闪退。
Chỉnh thế nào: 保持“内置（Wine）”（默认）。老游戏没有背景音乐或播放音乐时闪退，就试“原生（Windows）”；没改善就改回原来的选项。

[DirectPlay]
Là gì: 老式 Windows 游戏的联网（局域网、在线）库。
Vì sao chỉnh: 只在老游戏报 DirectPlay 错误，或进入联机模式时闪退才需要。单机游戏通常用不到。
Chỉnh thế nào: 保持“内置（Wine）”（默认）。只有游戏报与 DirectPlay 有关的错误时，才试“原生（Windows）”。

[DirectShow]
Là gì: DirectShow 视频播放库，游戏用它播放开场视频和游戏中的过场动画。
Vì sao chỉnh: 游戏里的视频黑屏、不播放、卡住，或播放视频时游戏闪退时调整。
Chỉnh thế nào: 保持“内置（Wine）”（默认）。视频出错就试“原生（Windows）”；没改善就改回“内置（Wine）”。

[DirectSound]
Là gì: 许多老式 Windows 游戏用来播放声音的 DirectSound 音频库。
Vì sao chỉnh: 老游戏没声音、有杂音或播放声音时闪退，而更换“音频驱动”也没用时调整。
Chỉnh thế nào: 保持“内置（Wine）”（默认）。老游戏声音出错就试“原生（Windows）”；没改善就改回“内置（Wine）”。

[Driver dựng hình]
Là gì: 应用把游戏画面画到屏幕上所用的 Vulkan 驱动（“渲染器”为 Vulkan 时）。这不是游戏使用的驱动；那个是“Vulkan 驱动”。
Vì sao chỉnh: 使用 Vulkan 渲染器时遇到黑屏、画面闪烁，或打开游戏时应用立刻自己关闭时调整。
Chỉnh thế nào: 建议保持“系统”（默认）。画面出错就试列表里的其他驱动（只有骁龙手机才有更多选项），或把“渲染器”改为 EGL。

[Driver OpenGL]
Là gì: 给使用 OpenGL（一种图形标准）的游戏，以及“Wine 渲染器”为 gl 时的 WineD3D 使用的驱动。Zink 在 Vulkan 驱动上运行 OpenGL；Freedreno 是 Adreno GPU 专用的 OpenGL 驱动。
Vì sao chỉnh: 你的 OpenGL 游戏黑屏、闪烁、颜色不对、自己关闭，或提示 OpenGL 版本不够时调整。
Chỉnh thế nào: Freedreno 只能在 Adreno GPU（骁龙手机）上运行，报告 OpenGL 3.3；Zink 在所有手机上都能运行。OpenGL 游戏画面出错、黑屏或自己关闭：试试另一个选项。联发科手机：选 Zink。

[Driver Vulkan]
Là gì: 游戏使用的主要图形驱动（通过 DXVK、VKD3D、Zink）。turnip26.2.0 是 Adreno GPU 的开源驱动，v863 是高通的驱动，System 是手机自带的驱动。
Vì sao chỉnh: 游戏黑屏、不显示 3D 画面、打开时自己关闭、画面出错或 FPS 低时调整。
Chỉnh thế nào: 骁龙手机：保持 turnip26.2.0（默认）。非骁龙手机：用 System。你选的驱动无法运行时，应用会在打开游戏时自动换用其他驱动。标有“下载”的项目会在选择时下载。

[Driver âm thanh]
Là gì: 把游戏声音送到手机扬声器的方式。PulseAudio-GN 是新版 PulseAudio，延迟低；PulseAudio 是旧版；ALSA 是应用内置的精简音频通道。
Vì sao chỉnh: 游戏没有声音、有杂音、噼啪响、声音延迟，或开始播放声音时游戏卡住时调整。
Chỉnh thế nào: 保持 PulseAudio-GN（默认）。没声音或有杂音：先试 PulseAudio，再试 ALSA。每次更改后，重新打开游戏检查。

[Driver đồ họa]
Là gì: 给使用 OpenGL 的游戏，以及用 gl 绘制时的 WineD3D 使用的 OpenGL 驱动。Wrapper 就是 Zink：在手机的 Vulkan 驱动上运行 OpenGL。
Vì sao chỉnh: 只有 OpenGL 游戏运行出错，并且你知道需要换别的驱动时才需要更改。
Chỉnh thế nào: 这个界面只有 Wrapper，保持不变即可。Vulkan 驱动在“驱动版本”中选择。

[DX Wrapper]
Là gì: 把 Windows 游戏的 DirectX 图形转换成手机能运行的形式。DXVK+VKD3D 转换成 Vulkan；WineD3D 是 Wine 自带的转换层。
Vì sao chỉnh: 你的 DirectX 游戏黑屏、画面出错、打开时自己关闭或运行太慢时调整。
Chỉnh thế nào: 建议保持 DXVK+VKD3D（默认，通常更快）。老游戏（DirectX 9 及更早）画面出错或打不开：试试 WineD3D。

[DXVK HUD]
Là gì: DXVK 把 Windows 游戏的 DirectX 图形命令转换成 Vulkan（手机能理解的绘图方式）。开启后，DXVK 会在左上角显示：FPS、GPU、驱动、GPU 占用。
Vì sao chỉnh: 排查图形问题时使用：看游戏是否在通过 DXVK 运行，以及有多少 FPS（每秒帧数）。
Chỉnh thế nào: 默认关闭。只有“DX Wrapper”为 DXVK+VKD3D 且游戏使用 DirectX 9 到 11 时才显示。平时玩建议关闭；想看 FPS 就用“HUD”。

[Dùng tiện ích DRI3]
Là gì: DRI3 让每一帧画面从图形芯片（GPU）直接送到游戏屏幕上。关闭后，画面要经过处理器（CPU）复制，会更慢。
Vì sao chỉnh: 只有游戏在开始显示画面时黑屏、闪烁、出现条纹或闪退，而更改其他图形设置都没用时，才建议试着关闭。
Chỉnh thế nào: 默认开启，建议保持开启，低配手机更是如此。此项对所有游戏生效。关闭后问题没改善就马上重新开启。

[Dùng tích hợp OpenXR]
Là gì: 此项只在 Meta Quest 虚拟现实头显上显示。开启后，游戏和运行环境会以虚拟现实模式打开，用头显的手柄操控。
Vì sao chỉnh: 想在头显里用普通的平面窗口玩，或虚拟现实模式画面出错、操控出错时关闭。
Chỉnh thế nào: 默认开启。在手机上此项不显示，也没有作用。

[FEXCore Preset]
Là gì: FEXCore 在速度和准确性之间的取舍档位。“稳定”：最安全、最慢。“性能”：最快、最容易出错。
Vì sao chỉnh: 游戏随机自己关闭或卡死、物理出错，或想给吃 CPU 的游戏多要一些 FPS 时调整。
Chỉnh thế nào: 建议保持“折中”（默认）。游戏随机自己关闭或卡死：先试“兼容”再试“稳定”。游戏运行正常但慢：试试“性能”，出错就改回来。

[Ghi đè di chuyển chuột]
Là gì: 对通过 DirectInput 读取鼠标的游戏（通常是老 3D 游戏），Wine 把鼠标指针拉回屏幕中央的方式：disable、enable 或 force。
Vì sao chỉnh: 用鼠标转镜头时卡在屏幕边缘，或指针总是被拉回屏幕中央时调整。
Chỉnh thế nào: 保持 disable（默认）。镜头转动卡住：先试 enable，再试 force。指针被拉回中央：改回 disable。

[Giao diện desktop]
Là gì: 运行环境中 Windows 风格的窗口、按钮、对话框的颜色：深色或浅色。不会改变游戏里的画面。
Vì sao chỉnh: 安装程序、错误提示框或游戏的设置窗口文字难以看清（深色背景上的深色文字）时调整。
Chỉnh thế nào: 默认“深色”。对话框难以看清就选“浅色”。下次打开时生效。

[Giá trị]
Là gì: 这一行环境变量的值。根据变量不同，你可以从列表中选择、勾选多项，或输入文字、数字。
Vì sao chỉnh: 有人指导你调整某个变量来修复画面、声音问题或测试性能时更改。
Chỉnh thế nào: 不要用空格，应用会自动去掉。多个项目用逗号分隔。不确定就用垃圾桶按钮删掉这个变量。重新打开游戏后生效。

[Giả lập 32-bit]
Là gì: 选择在手机芯片上运行 32 位 Windows 游戏和程序的模拟器。64 位游戏总是用 FEXCore 运行。
Vì sao chỉnh: 32 位游戏自己关闭、卡死、出错或运行慢时调整。
Chỉnh thế nào: 建议保持 FEXCore（默认）。32 位游戏出错或慢：试试 WOWBox64（会多出“WOWBox64 版本”和“Box64 预设”）。没改善就改回 FEXCore。

[Giả lập 64-bit]
Là gì: 显示正在运行 64 位程序的模拟器：arm64ec 版 Wine/Proton 用 FEXCore，其他版本的 Wine 用 Box64。此项只能查看。
Vì sao chỉnh: 不需要调整：它会随运行环境的 Wine/Proton 版本自动变化。
Chỉnh thế nào: 想用别的 64 位模拟器，就要用其他版本的 Wine/Proton 新建运行环境。模拟器的版本和预设在下面的选项中调整。

[Giả lập BCN]
Là gì: BCn 是 PC 游戏的纹理（表面图像）压缩格式，很多手机 GPU（尤其是 Mali）读不了。此项决定应用是否转换这些纹理。
Vì sao chỉnh: 看到纹理发黑、发紫、模糊、画面缺失，或游戏加载关卡时自己关闭时调整。
Chỉnh thế nào: 使用 Turnip 驱动的骁龙手机不需要此项：Turnip 能直接读取 BCn，应用会自动关闭它。其他驱动和 Mali 手机：保持 auto（默认）；full 转换所有纹理，最稳妥但耗 CPU 和内存；none：关闭。

[Giả lập màn hình cảm ứng]
Là gì: 点哪里，游戏就当作在那里按鼠标左键；按住拖动就是按住左键拖动。关闭后，屏幕变成触控板：滑动移动指针，轻点来点击。
Vì sao chỉnh: 非常适合视觉小说和点菜单类游戏：直接点选项即可。如果游戏需要只移动鼠标不点击（显示提示），或要转视角，就关闭。
Chỉnh thế nào: 通过 AGVN 导入的游戏通常已经开启；视觉小说建议保持不变。两种方式下，两指同时轻点都是鼠标右键。

[Giới hạn FPS]
Là gì: DXVK 的硬性 FPS 上限，适用于 DirectX 8–11 游戏。0 表示不限制。
Vì sao chỉnh: 游戏运行得太快，或 FPS 高时物理出错时使用。
Chỉnh thế nào: 保持 0（默认）。想让手机少发热，就打开游戏内菜单，在“画面”中把“FPS 上限”设为 30 或 20：60 Hz 屏幕只能均匀显示 60、30 和 20 FPS。只有游戏在 FPS 高时出错才在这里设数值：这是硬性锁定，在游戏里调不上去。

[Gửi mọi buffer]
Là gì: 仅在“渲染器”为 DisplayX 时才有。开启后，Android 会依次显示游戏送来的每一帧，不会丢掉旧帧直接跳到最新帧。
Vì sao chỉnh: FPS 正常但画面一顿一顿时，可能让动作更平滑。代价是操作可能稍有延迟。
Chỉnh thế nào: 保持关闭（默认）即可：优先显示最新帧，延迟更低。画面一顿一顿时试着开启，觉得延迟变大就关掉。只在 Android 12 及以上有效。

[Hiệu ứng làm nét]
Là gì: 给游戏画面加锐化滤镜。CAS 让细节更清晰又自然；DLS 锐化亮度，附带“锐化时降噪”滑块来减少噪点。
Vì sao chỉnh: 为了让手机轻松些而降低分辨率、画面变模糊时很有用。拖动“锐化程度”滑块来增减锐度。
Chỉnh thế nào: 默认 None。低配手机建议保持 None，因为锐化会多耗 GPU。想试试就选 CAS，程度适中。开启后画面没变化，说明这个游戏不吃这个效果，请保持 None。

[HUD]
Là gì: HUD 是叠在游戏上的小参数面板。“经典”：FPS（每秒帧数）、GPU 名称、内存。“现代”：再加上 CPU 和 GPU 占用、温度、电量、图表。
Vì sao chỉnh: 想看游戏流不流畅（FPS）、手机热不热、内存是否快不够时开启，尤其是在尝试新的图形设置时。
Chỉnh thế nào: 平时玩选“关闭”；想检查就选简洁的“经典”。此选择只对这个游戏生效。在游戏里也可以用菜单中的“开启 HUD”开关来开关。

[HUD Winlator]
Là gì: 玩游戏时显示在屏幕上的小参数面板。“经典”：FPS、GPU 名称、内存。“现代”：再加上 CPU/GPU 占用、温度、电量。
Vì sao chỉnh: 测试配置时开启来看 FPS，或用来找出游戏卡顿、手机发热的原因。
Chỉnh thế nào: 平时玩建议保持“关闭”。快速看 FPS：选“经典”。还想看温度、电量：选“现代”。适用于这个运行环境中还没单独选择 HUD 的游戏。

[Hình nền desktop]
Là gì: 模拟的 Windows 桌面的背景，位于游戏窗口后面：图片或纯色。
Vì sao chỉnh: 只是装饰。直接打开运行环境的 Windows 桌面时才会看到；从游戏库打开游戏时，背景通常被遮住。
Chỉnh thế nào: 选“图片”，再点“选择”或“更换”来使用你自己的图片。想简单就选“纯色”。

[Kiểu giả lập BCN]
Là gì: “BCn 模拟”为 auto 或 full 时，解压 BCn 纹理（PC 格式的压缩表面图像）的方式：compute 用 GPU，software 用 CPU。
Vì sao chỉnh: 游戏加载慢、进入新场景时卡顿，或纹理出错时调整。
Chỉnh thế nào: 建议保持 compute（默认）。在骁龙手机（Adreno GPU）上应用不使用 compute，所以此项无效。Mali 手机：纹理出错或游戏自己关闭时试试 software。

[Kéo giãn toàn màn hình]
Là gì: 把游戏画面拉伸铺满手机屏幕，去掉两侧的黑边。
Vì sao chỉnh: 想让画面占满整个屏幕时开启。如果分辨率的比例和屏幕比例不同，画面会被拉宽或变形。
Chỉnh thế nào: 默认关闭（保持正确比例）。想铺满屏幕又不变形，就选和手机比例相同的“分辨率”，例如 1280x576（20:9）。没有单独设置此项的游戏会跟随运行环境的选择。

[Loại tài nguyên]
Là gì: 驱动申请 CPU 和 GPU 共同读写的内存区域的方式。auto 会依次尝试 dmabuf、ahb、opaque，直到成功。
Vì sao chỉnh: 只在游戏打开或加载时自己关闭，或报图形内存错误时才更改。
Chỉnh thế nào: 建议保持 auto（默认）。如果游戏出现上面这些错误，依次试试 dmabuf、ahb、opaque；没改善就改回 auto。

[Lưu game]
Là gì: 为这个游戏单独开启存档（游戏进度）备份。应用会在虚拟 Windows 磁盘中找到存档文件夹，把副本放到 AGVN-Player/Saves 文件夹。
Vì sao chỉnh: 删除游戏、重装应用、更换运行环境或尝试陌生的设置之前，建议开启，以免丢失游戏进度。
Chỉnh thế nào: 点“立即备份”来保存，点“恢复”把最新的备份覆盖到当前存档上。如果游戏把存档直接放在游戏文件夹里（如许多 RPG Maker 游戏），此项不会备份。

[Lọc texture]
Là gì: 把游戏画面缩放到适合手机屏幕的方式。不会改变游戏里表面图像（纹理）的质量。EGL 渲染器只有 Bilinear 和“最近邻”。
Vì sao chỉnh: 看到画面模糊、颗粒感重，或想在低分辨率下画面更清晰时调整。
Chỉnh thế nào: 建议保持 Bilinear（平滑，默认）。像素风 2D 游戏：选“最近邻”。低配手机用低分辨率玩：试试 Snapdragon Super Resolution，画面更清晰。各种锐化方式和“色彩增强”会多耗 GPU。

[MIDI SoundFont]
Là gì: 用来播放 MIDI 音乐的乐器音色库。许多老游戏，如 RPG Maker 2000/2003 游戏，使用 MIDI 音乐。
Vì sao chỉnh: 设为“关闭”时，使用 MIDI 音乐的游戏没有背景音乐。换一个音色库可以改变音乐的音质。
Chỉnh thế nào: 游戏没有背景音乐：选 wt_210k_G.sf2（内置）。游戏不用 MIDI：保持“关闭”。在游戏设置中选择只改变这个游戏；在运行环境中选择则改变所有还没单独选择的游戏。

[Môi trường chạy]
Là gì: 运行环境是一台独立的虚拟 Windows 电脑，包含 Wine/Proton 版本（让 Windows 游戏运行的部分）、驱动和设置。此项显示游戏在哪个运行环境中运行。
Vì sao chỉnh: 游戏在当前的 Wine/Proton 版本下无法运行或经常出错，或你想给这个游戏单独设置、不影响其他游戏时更换。
Chỉnh thế nào: 选择其他运行环境会把游戏复制过去，原来那份还在。存档不会自动跟过去：请先备份，再在新的那份中恢复。只有一个运行环境时，点 + 新建一个。

[Mở chế độ Big Picture khi khởi động]
Là gì: Big Picture 是大尺寸的选游戏界面，按封面浏览，适合电视或手柄。开启后，每次打开应用都会直接进入这个界面。
Vì sao chỉnh: 在电视、大屏幕上玩，或主要用手柄时开启。这个界面有背景音乐，游戏没有封面时会通过网络自动下载封面。
Chỉnh thế nào: 默认关闭；低配手机建议保持关闭，更轻快。在 Big Picture 中按返回键可以回到普通界面。背景音乐可以在 Big Picture 的设置中关闭。

[Mở trình duyệt Android từ Wine]
Là gì: 游戏打开网页时（官网按钮、论坛、赞助作者…），网页会用你手机上的浏览器打开。
Vì sao chỉnh: 需要从游戏里打开网页时开启，例如攻略页面或游戏更新的下载页面。
Chỉnh thế nào: 默认关闭。开启后，游戏打开网页时你会被切换到浏览器，游戏暂停；回到应用就能继续玩。

[Mức tính năng VKD3D]
Là gì: VKD3D 告诉游戏的 DirectX 12 功能级别。只在“VKD3D 版本”不是 None 时有效。
Vì sao chỉnh: DirectX 12 游戏提示不支持该功能级别、打不开或进入时自己关闭时调整。
Chỉnh thế nào: 建议保持 12_1（默认）。游戏要求更高级别：试试 12_2。打开时自己关闭：试试 12_0 或 11_1。VKD3D 会忽略 10_x 和 9_x 级别。

[Ngôn ngữ vùng (LC_ALL)]
Là gì: 模拟的 Windows 告诉游戏的语言和地区。它决定文字编码，对老的日文、中文游戏非常重要。
Vì sao chỉnh: 地区不对时，日文游戏（KiriKiri、Siglus、NScripter、Wolf RPG…）可能乱码、文件名出错或闪退。越南语翻译版通常保持 ja_JP 也能正常显示。
Chỉnh thế nào: 添加游戏时，应用会自动为日文游戏选择 ja_JP。乱码或闪退：日文游戏选 ja_JP，中文游戏选 zh_CN 或 zh_TW。没有问题就保持不变。

[Nhập độc quyền]
Là gì: 开启后，你为游戏选一种手柄方式：XInput 或 DInput；两个都关的话，游戏识别不到手柄。关闭后，游戏通过两种方式都能看到手柄。适用于实体手柄和虚拟手柄，不影响鼠标、键盘。
Vì sao chỉnh: 开启可以避免游戏把手柄识别两次（按一个键出两个指令）。有些使用 DInput 的游戏，如 Rayman Origins 或 NFS Most Wanted 2005，需要关闭此项。
Chỉnh thế nào: 默认开启，使用 XInput。老游戏识别不到手柄：打开“开启 DInput”。还是不行就关闭“独占输入”。

[Phiên bản Box64]
Là gì: Box64 把电脑程序的代码（x86-64）转换成手机芯片（ARM）的代码，用来运行 Wine 和游戏。只有 Wine/Proton 不是 arm64ec 版时才有此项。
Vì sao chỉnh: 游戏闪退、卡死、运行慢或出现奇怪错误，或有人指导你使用某个 Box64 版本时调整。
Chỉnh thế nào: 默认：0.4.2（内置）。标有“下载”的版本需要联网下载。换了以后游戏错误更多，就改回 0.4.2。低配手机：保持默认即可。

[Phiên bản DXVK]
Là gì: 把 DirectX 8–11 转换成 Vulkan 的 DXVK 版本。带 arm64ec 的版本让 64 位游戏直接在手机芯片上运行；带 async 或 gplasync 的版本在后台编译着色器（特效代码）。
Vì sao chỉnh: 游戏画面出错、打开时自己关闭，或遇到新特效时经常卡顿时调整。
Chỉnh thế nào: 默认 2.3.1（Mali 手机：1.10.3）。Mali 手机或旧驱动：用 1.10.3。使用 VKD3D 需要 2.x 版本。低配手机、64 位游戏：可以试试 arm64ec 版，出错就改回来。

[Phiên bản FEXCore]
Là gì: FEXCore 的版本，它是在手机芯片上运行游戏的电脑代码（x86）的模拟器。用于 64 位游戏，以及选择了 FEXCore 的 32 位游戏。
Vì sao chỉnh: 游戏自己关闭、卡死或运行不正常，而更换“FEXCore 预设”没用时调整。
Chỉnh thế nào: 建议保持 2601（内置版本，默认）。只在游戏出错时才试其他版本；标有“下载”的版本需要联网下载。错误更多就改回 2601。

[Phiên bản VKD3D]
Là gì: VKD3D-Proton 把 DirectX 12 转换成 Vulkan。None 表示不使用，只剩 Wine 自带的 DirectX 12，功能非常有限。
Vì sao chỉnh: DirectX 12 游戏需要此项；设为 None 时，DirectX 12 游戏通常无法运行。
Chỉnh thế nào: 不是 DirectX 12 的游戏：保持 None（默认）。DirectX 12 游戏：选 2.14.1，出错就试 2.8；DXVK 必须是 2.x 版本。DirectX 12 游戏很吃配置，低配手机很难流畅运行。

[Phiên bản Vulkan]
Là gì: 告诉游戏的 Vulkan（DXVK、VKD3D、Zink 使用的图形标准）版本号。此项只改变报告的数字，不会让驱动变强或变弱。
Vì sao chỉnh: 很少需要更改。游戏没问题就保持默认。
Chỉnh thế nào: 保持 1.3（默认）。DXVK 2.x 和 VKD3D 需要 1.3：降到 1.2 或 1.1 它们就无法运行。只有游戏用 DXVK 1.10.3 或 WineD3D 仍然出错时才试着调低。

[Phiên bản WOWBox64]
Là gì: WOWBox64 是在 arm64ec 版 Wine/Proton 上运行 32 位程序（通常是老游戏）的 Box64 版本。只在“32 位模拟器”为 WOWBox64 时使用。
Vì sao chỉnh: 32 位游戏闪退、卡死、运行慢或出现奇怪错误，或有人指导你使用某个版本时调整。
Chỉnh thế nào: 默认：0.4.2（内置）。标有“下载”的版本需要联网下载。换了以后游戏错误更多，就改回 0.4.2。

[Preset Box64]
Là gì: Box64 和 WOWBox64 的预设，在稳定和速度之间取舍：稳定、兼容、折中、性能（从最安全到最快）。
Vì sao chỉnh: 游戏闪退、卡死或出现奇怪错误时调整（选更安全的档），或游戏运行正常但慢时调整（选更快的档）。
Chỉnh thế nào: 默认：“兼容”。游戏出错：试试“稳定”。想更快：先试“折中”再试“性能”，出错就改回来。Unity 游戏建议用“兼容”或“稳定”。

[Preset FEXCore]
Là gì: FEXCore 的预设，在稳定和速度之间取舍：稳定、兼容、折中、性能（从最安全到最快）。
Vì sao chỉnh: 游戏闪退、卡死或出现奇怪错误时调整（选更安全的档），或游戏运行正常但慢时调整（选更快的档）。
Chỉnh thế nào: 默认：“折中”。游戏出错，尤其是多线程的游戏：先试“兼容”再试“稳定”。想更快：试试“性能”，出错就改回“折中”。

[Processor Affinity (32-bit apps)]
Là gì: 为这个运行环境中运行的 32 位 Windows 程序选择 CPU 核心。
Vì sao chỉnh: 游戏已在“选择 CPU 核心”中选了核心的，32 位程序也用这些核心；没选的游戏才用此项。很少需要更改。
Chỉnh thế nào: 保持默认不变。想试试的话，只保留大核，通常是编号大的（例如 CPU4–CPU7）。

[Renderer]
Là gì: 应用把游戏画面画到手机屏幕上的方式：Vulkan（默认）或 EGL（用 OpenGL ES 的传统绘制方式）。
Vì sao chỉnh: 黑屏、闪烁、画面出错，或打开游戏时应用立刻退出时调整。
Chỉnh thế nào: 默认：Vulkan（带 Snapdragon Super Resolution 等滤镜）。遇到显示问题：试试 EGL；EGL 只有 Bilinear 和“最近邻”滤镜。重新打开游戏后生效。

[Toàn màn hình cho mọi game]
Là gì: 把所有游戏的画面拉伸铺满手机屏幕，两侧不再有黑边，Windows 游戏和轻量运行的游戏都适用。
Vì sao chỉnh: 想让游戏画面占满整个屏幕时开启。手机屏幕比游戏画面更长，所以画面会稍微横向拉宽（人物会显得胖一点）。
Chỉnh thế nào: 默认关闭（保持正确比例）。在游戏设置中单独选了“拉伸全屏”的游戏，会按那个游戏的选择。下次打开游戏时生效。

[Sao lưu bản lưu cho mọi game]
Là gì: 开启后，每次游戏关闭时，应用会自动找到游戏的存档，压缩到手机存储的 AGVN-Player/Saves/<游戏名>/ 文件夹中。
Vì sao chỉnh: 开启后，游戏出错、误删数据或重装应用时不容易丢失游戏进度。
Chỉnh thế nào: 默认：关闭。只能备份应用找得到独立存档文件夹的游戏。每个游戏保留一份最新的自动备份；想多留几份，就在“游戏存档”中点“立即备份”。

[Shader Async]
Là gì: 让 DXVK 在后台构建着色器（生成画面特效的小程序），游戏不用停下来等。只对名字带 async 或 gplasync 的 DXVK 版本有效。
Vì sao chỉnh: 游戏每次遇到新场景、新物体或新特效都卡一下时开启。
Chỉnh thế nào: 默认：关闭。游戏卡顿就试着开启；代价是物体或特效可能会晚一点出现。看到画面缺东西或闪烁就关闭。重新打开游戏后生效。

[Tiện ích Vulkan đã tắt]
Là gì: 应用隐藏起来的 Vulkan 扩展（图形驱动的附加功能）列表，让游戏和 DXVK、VKD3D、Zink 不去用它们。名称之间用逗号分隔。
Vì sao chỉnh: 驱动的某个扩展让游戏闪退、黑屏或画面出错时使用；把它隐藏后，游戏就得换别的方式。
Chỉnh thế nào: 默认：留空。只在有人指导时填写，输入准确的名称（以 VK_ 开头）。空格会被去掉。游戏错误更多就清空。重新打开游戏后生效。

[Trình chiếu chính xác]
Là gì: 仅在“渲染器”为 DisplayX 时才有。开启后，每一帧都按 Android 提供的时间点，对准屏幕的某一次刷新。
Vì sao chỉnh: FPS 不低但仍觉得画面有点卡时，可能让画面显示更均匀。
Chỉnh thế nào: 保持关闭（默认）即可。画面有点卡就试着开启；没区别或觉得延迟变大就关掉。只在 Android 13 及以上有效，更老的手机会忽略。

[Trình chiếu theo tần số quét]
Là gì: 仅限 DisplayX。开启：画面会被汇总，按手机刷新率的节奏送上屏幕。关闭：游戏画完就立即送出。
Vì sao chỉnh: 开启让画面跟着屏幕均匀输出。关闭可能降低操作延迟，但画面可能不均匀。
Chỉnh thế nào: 默认开启。觉得操作有延迟就试着关闭；画面卡顿或闪烁就重新开启。

[Tên]
Là gì: 运行环境或游戏的名称（显示在游戏库中）。在“添加环境变量”对话框中，这是你自己输入的变量名。
Vì sao chỉnh: 名称帮你区分游戏和运行环境，不会改变游戏的运行方式。但变量名必须输入正确，变量才会生效。
Chỉnh thế nào: 游戏名不能使用 \ / : * ? " < > |（会变成 _）。改了游戏名后，旧的备份仍在以旧名称命名的文件夹里。变量名要连着写，例如 DXVK_HUD。

[Tên GPU]
Là gì: 游戏看到的显卡名称。Device 是手机真实的 GPU 名称；选其他名称可以伪装成电脑显卡（同时更改厂商 ID 和显卡 ID）。
Vì sao chỉnh: 有些游戏看到手机 GPU 时不肯运行、提示显卡不受支持，或自动选错设置。
Chỉnh thế nào: 建议保持 Device（默认）。游戏提示不支持显卡：试试 NVIDIA GeForce GTX 1060。此项不会让手机变强。

[Tính shader chính xác]
Là gì: 开启后，WineD3D 会要求驱动不要使用快速但近似的着色器（生成画面特效的小程序）计算方式。只在 WineD3D 使用 gl 渲染时有效。
Vì sao chỉnh: 很少需要更改。对于应用的 OpenGL 驱动（Zink、Freedreno），此项在速度和画面上几乎没有区别。
Chỉnh thế nào: 默认：开启。游戏运行正常就保持不变。如果关闭后没区别或画面更糟，就重新开启。

[Tạm dừng game khi ứng dụng chạy nền]
Là gì: 你离开应用时（回到主屏幕、打开其他应用或关闭屏幕），游戏会完全暂停，不在后台运行。
Vì sao chỉnh: 暂时离开游戏时帮你省电、减少发热；回到应用后游戏继续运行。
Chỉnh thế nào: 建议保持开启（默认）。在这个版本中，不管开关开还是关，你离开应用时游戏都会暂停。想在做别的事时让游戏继续运行，就用游戏菜单里的“画中画”。

[Tắt chuột]
Là gì: 在屏幕上点击和滑动将不再控制游戏里的鼠标。虚拟按键、手柄和外接鼠标仍可正常使用。
Vì sao chỉnh: 完全用虚拟按键或手柄玩，又经常误触让指针乱跑、点错时开启。
Chỉnh thế nào: 默认关闭。开启后，四指轻点不能再打开菜单，请用返回键。可以直接在游戏菜单里开关（“关闭鼠标”开关）。

[Tắt Present Wait]
Là gì: 关闭驱动的 present wait 功能。这个功能让游戏（通过 DXVK 2.x、VKD3D）等到画面真正显示到屏幕上，再来对齐节奏。
Vì sao chỉnh: 对某些驱动来说，这个功能可能让游戏画面定住、卡死或有规律地卡顿。
Chỉnh thế nào: 保持关闭（默认）即可。游戏玩着玩着画面定住或卡死，或有规律地卡顿：试着开启；没改善就关掉。不影响 DXVK 1.10.3。

[Tắt XInput]
Là gì: 开启后，这个游戏不识别任何手柄（实体手柄或虚拟按键中的手柄按键），只识别鼠标和键盘。映射到键盘或鼠标的虚拟按键仍可使用。
Vì sao chỉnh: 用于手柄让这个游戏按键错乱或角色自己乱跑的情况。
Chỉnh thế nào: 保持关闭（默认）。只有这个游戏因为手柄出错时才开启。想为所有游戏关闭手柄，就用“设置”中的“关闭 XInput（只用鼠标/键盘）”。改完后重新打开游戏。

[Tắt XInput (chỉ dùng chuột/bàn phím)]
Là gì: 开启后，所有游戏都不识别任何手柄（实体手柄或虚拟按键中的手柄按键），只识别鼠标和键盘。映射到键盘或鼠标的虚拟按键仍可使用。
Vì sao chỉnh: 用于手柄（实体手柄或虚拟按键中的手柄按键）让游戏按键错乱或角色自己乱跑的情况。
Chỉnh thế nào: 保持关闭（默认）。只想为某个游戏关闭，就用那个游戏设置中的“关闭 XInput”。改完后重新打开游戏。

[Tự động sao lưu]
Là gì: 每次游戏关闭时，应用会自动备份游戏的存档文件夹。新的自动备份总是替换旧的自动备份，不会动你自己备份的那些。
Vì sao chỉnh: 开启后就不用记着去点备份，以防存档损坏或误删游戏。
Chỉnh thế nào: 只有应用找到了独立的存档文件夹才会运行（见“存档位置”）。请用游戏菜单里的电源按钮退出，不要划掉应用。开启“为所有游戏备份存档”后，此项会一直开启。

[Visual C++ 2010]
Là gì: 许多游戏和工具需要的 Visual C++ 2010 运行库（msvcp100、msvcr100），没有它就打不开。
Vì sao chỉnh: “原生（Windows）”能让需要 Visual C++ 2010 的游戏稳定运行。Wine 的版本有时缺少功能，会让游戏打开时报错或闪退。
Chỉnh thế nào: 保持“原生（Windows）”（默认）。不建议改为“内置（Wine）”，除非有针对那个游戏的专门指导。

[Vẽ ngoài màn hình]
Là gì: WineD3D 绘制还没显示到屏幕上的临时画面的方式：fbo（新方式）或 backbuffer（旧方式）。只在 WineD3D 使用 gl 渲染时有效。
Vì sao chỉnh: 只在使用 WineD3D 的游戏黑屏或画面出错，其他办法都修不好时才更改。
Chỉnh thế nào: 默认：fbo，建议保持不变。其他办法都试过后才试 backbuffer；更糟就改回 fbo。重新打开游戏后生效。

[Wine / Proton]
Là gì: 用来运行 Windows 游戏的 Wine/Proton 版本。arm64ec 版直接在手机芯片上运行 Wine，只模拟游戏的 x86 代码；x86_64 版则通过 Box64 模拟全部内容。
Vì sao chỉnh: 不同版本适合不同的游戏。游戏打不开或闪退，而调整其他选项都没用时更换。
Chỉnh thế nào: 建议用 Proton 9 arm64ec（内置，通常更快）。只能在新建运行环境时选择；标有 Download 的版本要先下载。游戏出错就试着用其他版本新建一个运行环境。

[XAudio]
Là gì: 许多 DirectX 9–11 游戏用来播放声音的音频库 XAudio2、X3DAudio、XACT（2.0 到 2.7 版）。
Vì sao chỉnh: 游戏没声音、有杂音、声音重复，或播放声音时游戏闪退时调整。
Chỉnh thế nào: 保持“内置（Wine）”（默认）。声音出错就试“原生（Windows）”。使用 XAudio 2.8/2.9 的新游戏不受此项影响。

[Đặt khóa API SteamGrid? (Ảnh bìa)]
Là gì: 允许你输入封面服务 SteamGridDB 的个人密钥。API 密钥是一串个人代码，让应用获准从该服务下载图片。
Vì sao chỉnh: Big Picture 模式会用应用自带的密钥从 SteamGridDB 自动下载封面。只有那里的封面下载不了时，才需要个人密钥。
Chỉnh thế nào: 默认关闭，通常不需要开启。开启后把密钥粘贴到“SteamGridDB API 密钥”框里，点“保存”；关闭会删除已保存的密钥。游戏库里的封面是在手机上生成的，不使用这个密钥。

[Định dạng bề mặt]
Là gì: 游戏和应用交换画面时使用的颜色通道顺序（RGBA 或 BGRA）。
Vì sao chỉnh: 格式不对会让颜色颠倒，例如红色变成蓝色、人的皮肤发蓝。
Chỉnh thế nào: 保持默认：Vulkan 和 EGL 用 BGRA，DisplayX 用 RGBA（更换“渲染器”时会自动设置）。颜色颠倒就选另一个值。

[Đồng bộ cấu trúc CPU]
Là gì: 开启后，Wine 告诉游戏的只是你在“选择 CPU 核心”中选的那些核心，而不是手机的全部核心。
Vì sao chỉnh: 如果去掉了一些核心，游戏却仍以为核心齐全，可能会把工作分给太多线程而卡顿。开启后，游戏会按实际能用的核心数来分配工作。
Chỉnh thế nào: 默认关闭。只有在“选择 CPU 核心”中去掉了部分核心时才建议开启。游戏变慢或出错就关掉。

[Đồng bộ khung hình]
Là gì: 让游戏等 GPU 画完每一帧，再送上屏幕。
Vì sao chỉnh: 可能修复画面闪烁、闪黑或某些帧画面出错；代价是 FPS 降低。
Chỉnh thế nào: 保持关闭（默认）即可。只有画面闪烁或出错，且更改“驱动呈现模式”也没用时才开启。低配手机建议保持关闭，因为会降低 FPS。

[Đổi kênh màu đỏ/xanh dương]
Là gì: 用 Vulkan 绘制时，交换游戏画面中的红色和蓝色。
Vì sao chỉnh: 只在游戏颜色颠倒时使用，例如人的皮肤变蓝、火焰是蓝色的。
Chỉnh thế nào: 默认：关闭。只在颜色颠倒时试着开启。如果颜色没变化，就关掉，再试着更改运行环境“画面”部分中的“表面格式”（RGBA/BGRA）。

[Độ phân giải]
Là gì: 游戏绘制的模拟 Windows 屏幕的尺寸，之后会缩放到适合手机屏幕。
Vì sao chỉnh: 调低更轻快、手机更凉（但不会快一倍），画面更模糊。调高更清晰，但更吃配置、更热。
Chỉnh thế nào: 低配手机：854x480（16:9）；中端：960x544（16:9）；高端：1280x720（16:9）。通过应用添加的游戏已有自己的档位，游戏库里的“调整画质”也会改它。选 Custom 可以自己输入。

[Độ phân giải tùy chỉnh]
Là gì: 用来自己输入分辨率的框，在“分辨率”中选择 Custom 时显示。
Vì sao chỉnh: 需要列表中没有的尺寸时使用，例如配合手机屏幕的比例，或为低配手机再调低一些。
Chỉnh thế nào: 按“宽x高”的格式输入，例如 1024x576；x 大小写都可以，每边 200 到 7680。输错的话应用会保留原来的分辨率。低配手机建议保持在 854x480 到 960x544 左右。

[Độ trễ khung hình tối đa]
Là gì: 开启后，DXVK 只允许游戏最多提前准备 1 帧（DirectX 10/11 游戏）。
Vì sao chỉnh: 降低从你按下到画面响应之间的延迟，适合动作游戏。
Chỉnh thế nào: 保持关闭（默认）即可。觉得操作有延迟就开启；FPS 下降或更卡就关掉。低配手机建议保持关闭。

[Ẩn thanh tải khi mở game]
Là gì: 去掉打开游戏时的“正在启动…”等待界面（游戏名、封面、进度条），以及退出游戏时的等待界面。
Vì sao chỉnh: 如果游戏常常一直卡在“正在启动…”界面就开启：没有等待界面时，你仍然可以用返回键打开游戏菜单来退出。
Chỉnh thế nào: 默认关闭。开启并不会让游戏打开得更快。游戏加载时你可能会看到几秒黑屏，这是正常的。
